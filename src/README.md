# 源代码预留目录

本次没有创建业务代码。未来仅设置五个用户入口：

| 计划文件 | 职责 | 文件所有者 |
| --- | --- | --- |
| `01_preprocess.py` | 影像与边界预处理 | A |
| `02_samples.py` | 特征与样本提取、独立留出划分 | B |
| `03_classify.py` | 按年份训练随机森林并输出分类 | C |
| `04_evaluate.py` | 去噪、矢量化、独立评价 | D |
| `05_analyze.py` | 两期变化与街镇统计 | E |

共享配置和类型由集成负责人 I 管理，算法分别放入 `rs_urban/` 的单一职责模块；详细文件清单见[并发计划](../docs/superpowers/plans/2026-10-14-first-release-parallel-plan.md)。这是一套离线脚本，不建设通用任务框架。
