# 自建辐射定标 + 大气校正：结果与 L2SP 对比

> 用 Level-1 原始 DN 自行完成定标与大气校正，并与 USGS L2SP 成品逐波段比对。
> 仅作验证，未替换正式成果。

## 1. 方法

| 步骤 | 做法 |
| --- | --- |
| 定标（TM） | `L = RADIANCE_MULT·DN + RADIANCE_ADD`，再 `ρ_TOA = π·L·d²/(ESUN·cos θs)` |
| 定标（OLI） | `ρ_TOA = (REFLECTANCE_MULT·DN + REFLECTANCE_ADD)/sin θs` |
| 大气校正 | 暗像元法：取每波段 1% 分位为路径反射率 `ρ_path`，`ρ_s = (ρ_TOA − ρ_path)/(Tz·Tv)`，`Tz = exp(−τr/cos θs)`，`Tv = exp(−τr)` |
| Rayleigh 光学厚度 | `τr = 0.008569·λ⁻⁴(1 + 0.0113λ⁻² + 0.00013λ⁻⁴)` |
| 重采样 | 双线性重投影到分析网格（与 `sr_30m.tif` 完全对齐） |

局限：DOS 不做气溶胶、水汽、邻域效应与地形校正；L2SP 用带辅助数据的辐射传输模型。
两者有差是必然的，本节只量化差多少。

## 5. 结论

- 偏差最大的波段：1992 年 nir，偏差 0.1303。
- DOS1 变体 NDVI 平均绝对差：1992 0.2264、2021 0.1040。
- DOS+Rayleigh 变体 NDVI 平均绝对差：1992 0.2203、2021 0.0825（NDVI≥0.66 面积 1992 456.3 km²、2021 272.5 km²）。
- **空间结构一致、绝对量级不可比**：六个波段与 L2SP 的相关系数在 0.85—1.00，但自建反射率整体偏低（如 1992 年蓝 0.011 vs 0.064、近红外 0.191 vs 0.321）。
- **原因**：DOS 假设暗像元地表反射率为 0。1992 年场景雾霾重，连最暗的 0.05% 像元在 L2SP 里仍有可观反射率（近红外 0.01 分位为 0.128），按 0 扣除必然过度，剩余信号被压到接近 0。
- **后果**：NDVI 系统性偏高 0.10—0.21，`NDVI ≥ 0.66` 的面积从 L2SP 的 70.9 km² 涨到 461.2 km²（1992）。这是比值指数在等量扣除路径辐射后的固有放大效应。
- 逐波段线性关系可用来做相对比较，但不能定量替代辐射传输模型；L2SP 有气溶胶反演、水汽与臭氧辅助数据，DOS 一项都没有。
- **结论**：自建一阶校正（DOS）不满足替换条件，**正式成果继续使用 L2SP**；本节交付的是「自行完成定标与大气校正」的实现与量化证据，用来说明为什么这一步最终采用成品。
