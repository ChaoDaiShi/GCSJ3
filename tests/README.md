# 测试预留目录

当前没有测试代码或测试数据。后续测试按工作线划分：`unit/`、`integration/`、`acceptance/`，由对应模块负责人拥有自己的文件。

合成微型栅格仅验证缩放、掩膜、网格、指数、分组隔离、类别和面积计算等确定性行为。真实影像、独立样本、GIS 打开结果和完整流程证据用于最终验收。二者分开记录。

未来测试命令及每个用例的输入、预期结果见[并发计划](../docs/superpowers/plans/2026-10-14-first-release-parallel-plan.md)与[验收矩阵](../docs/04-acceptance.md)。
