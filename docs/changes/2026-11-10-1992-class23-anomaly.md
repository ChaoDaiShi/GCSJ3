# 2026-11-10　1992 年耕地/林草分类异常：判定与处理

## 背景

改用两期人工判读样本并加入像元纯度过滤后，1992 年分类结果出现明显异常：

| 类 | 1992 | 2021 |
| --- | ---: | ---: |
| 城镇及建设用地 | 21.4 km²（4.3%） | 111.8 km²（22.6%） |
| 耕地 | **68.7 km²（13.9%）** | 208.1 km²（42.1%） |
| 林草植被 | **399.3 km²（80.9%）** | 168.9 km²（34.2%） |
| 水体 | 4.1 km²（0.8%） | 5.2 km²（1.1%） |

1992 年新都是农业县，耕地应占 75%—80%，实际却只有 13.9%，林草反占 80.9%。

## 判定

**保留四类，如实记录异常，不做任何数字修正。**

曾被提出但已否决的三条路径：

| 方案 | 否决理由 |
| --- | --- |
| 交换耕地与林草的类别标签 | 属于伪造：会声称 1992 年 80% 是林地，且会把正确的 2021 年一并改错 |
| 用算法重新自动生成耕地/林草样本 | 结果完全由阈值决定（见下），且会毁掉唯一不依赖阈值的人工判读证据 |
| 调参或换特征强行修正 | 无法解决光谱重叠，只会把偏差藏到别处 |

## 成因（三条实测证据）

1. **样本光谱位置倒挂**：12 个耕地面 NDVI 均值 0.655—0.722，12 个林草面 0.618—0.662。耕地（水稻抽穗）比林草还绿。
2. **全区 NDVI 集中**：中位 0.63、90 分位 0.67，超过 0.70 的仅 1%；稻田与林木差异不足 0.04。
3. **阈值敏感性**：

| 阈值 | 林草面积 km² |
| --- | ---: |
| NDVI ≥ 0.60 | 359 |
| NDVI ≥ 0.62 | 285 |
| NDVI ≥ 0.64 | 180 |
| NDVI ≥ 0.66 | 71 |
| NDVI ≥ 0.68 | 14 |

阈值差 0.02 → 面积差 25 倍，说明该类面积由阈值选择决定，不具备地理意义。

## 影响范围

- **不受影响**：建设用地面积、净增量、街镇排序、扩张空间格局（城镇类判别与耕地/林草相互独立）。
- **受影响**：1992 年耕地、林草分项面积不可引用；2021 年两类面积有 ±5% 量级不确定性。

## 稳健性检验

`tools/merge_three_class.py` 把耕地与林草合并为「植被」后重算：建成区净增 89.94 km²，与四类口径 89.47 km² 相差 0.5%。主要结论不依赖二级类划分。

## 后续改进

增补 1992 年 3—4 月影像（冬小麦返青期），耕地与林木 NDVI 可拉开 0.2 以上。单期夏季影像无法可靠分离这两类。
