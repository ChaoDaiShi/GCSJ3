# 遥感影像解译与样本标注规范手册 v1

**适用范围：** 成都市新都区 1992 年（Landsat 5 TM）与 2021 年（Landsat 8 OLI）地表覆盖分类样本采集与独立留出评价。  
**依据文档：** [公共契约 v1](03-contracts.md)、[第一阶段设计](superpowers/specs/2026-10-14-first-release-design.md)。  
**所有者与分工：** 内容口径由样本负责人 B 制定，排版与格式由制图负责人 F 维护。

---

## 1. 统一地类定义与判读特征

本项目采用五类标准分类体系，编码 1—5，0 为 NoData：

| 类别编码 | 类别名称 | 代表地物与范围界定 | 典型假彩色特征（TM: 4-3-2 / OLI: 5-4-3） | 注意事项与混淆排查 |
| :---: | :---: | :--- | :--- | :--- |
| **1** | **建设用地** | 城镇与乡村建筑群、工业厂房、仓储区、硬化道路、广场与硬质铺装地面、农村集中居民点。 | 灰白、青蓝、浅紫灰或灰褐色，纹理规则，具几何轮廓。 | 不得以行政区划推定；农村分散硬化院落按建设用地；正在开挖平整但尚未铺装施工的大片裸露地基划归**裸地**。 |
| **2** | **耕地** | 水田、水浇地、旱地、蔬菜大棚、休耕地。 | 8 月 TM（生长期）：鲜红至粉红，大片规则田块；2 月 OLI（越冬/休耕）：浅红、黄灰或淡绿。 | 1992 年 8 月植被繁茂，注意与草地林地依田块轮廓区分；2021 年 2 月休耕田块地表较干，避免与裸地混淆（参考历史轮廓与 NDVI/BSI）。 |
| **3** | **其他植被** | 乔木林、灌木林、果园、苗圃、公园人工绿化林地、草地与荒草地。 | 深红、暗红至鲜红色，质感粗糙，多沿河流两侧、林盘、山丘或苗圃成片分布。 | 居民点内部的高密度行道树/林盘若像元尺度混杂，应尽量避开混合区，选择大面积成片植被标注。 |
| **4** | **水域** | 天然河流（如毗河、锦江支流）、人工水渠、水库、池塘、水产养殖坑塘。 | 深蓝、暗蓝至近黑色，轮廓清晰平滑，在短波红外波段具有强吸收特性。 | 水生植物覆盖密集的浮萍浅水塘需结合 MNDWI 检验；枯水期暴露的干涸沙滩归**裸地**。 |
| **5** | **裸地** | 自然裸露沙石、干涸河滩、大面积平整待建工地、未硬化推土地块。 | 高亮度白、灰白或浅黄褐，形状多不规则，无植被红外反射特征。 | 须严格与已浇筑硬化地基（归建设用地）区分；避免把已收割微薄残留秸秆的农田误划为裸地。 |

## 2. 空间独立分组与样本隔离规则

为保证训练集与验证集的科学独立性，**严禁按像元随机抽样划分**。必须按地块空间组（`group_id`）实施分层留出：

1. **地块组原则（Spatial Grouping）：**
   - 每一个标注多边形代表一个独立空间实体，赋予唯一的 `group_id`（例如 `c1_g01`、`c1_g02`）。
   - 同一个物理地块内若包含多个相连或相邻多边形，**必须共用同一个 `group_id`**，不得拆分为多个组以防空间自相关渗漏。
   - 空间不相邻、物理隔离的不同地块赋予不同的 `group_id`。
2. **每类样本容量基线：**
   - 每一类别在全区范围内至少标注 **8 个在空间上分散分布的地块组**。
   - 组的多边形内部需包含足够数量的纯像元，确保类内变异性（如不同建筑材质、不同作物茬口）。
3. **分层留出划分（GroupShuffleSplit）：**
   - 采用 `GroupShuffleSplit(n_splits=1, test_size=0.25, random_state=42)`。
   - 对每个类别分别独立进行分组划分，确保**每个类别均有至少 2 个独立组**进入最终评价集合（`holdout`）。
   - 划分完成后导出 `data/processed/samples/{year}/split.json` 并立即冻结。后续调参、特征提取和训练均严格沿用该划分，不得因精度不达标而随意调换 holdout 组。
4. **像元隔离验证：**
   - 提取的像元中心坐标在 `train.csv` 与 `holdout.csv` 之间**交集严格为空**。
   - `group_id` 集合在 `train` 与 `holdout` 之间**交集严格为空**。

## 3. 矢量图层结构与标注操作规范

在 QGIS 3.44 LTR 中新建/编辑 GeoPackage 文件：
- 路径：`data/samples/{year}/labels.gpkg`
- 图层名：`labels`
- 几何类型：`Polygon` 或 `MultiPolygon`
- 坐标参照系：`EPSG:32648` (WGS 84 / UTM zone 48N)

### 图层属性表规范：

| 字段名 | 类型 | 约束 / 取值范围 | 说明 |
| :--- | :--- | :--- | :--- |
| `sample_id` | String | 唯一主键，如 `s_1992_0001` | 样本多边形唯一编号 |
| `group_id` | String | 如 `c1_g01`，同地块共用 | 空间地块组编号 |
| `year` | Integer | `1992` 或 `2021` | 影像年份 |
| `class_id` | Integer | `1` 到 `5` | 五类编码 |
| `label_source` | String | 如 `Landsat5_TM_RGB432`、`HistoricalMap` | 判读依据来源 |
| `source_date` | String | ISO 日期，如 `1992-08-16` | 依据资料的时相 |
| `annotator` | String | 标注人员代号/姓名拼音 | 质量追溯责任人 |
| `split` | String | `unassigned` / `train` / `holdout` | 初始置为 `unassigned`，由代码统一划分 |

## 4. 判读与质量控制守则

1. **时相严格对齐：**
   - 1992 年样本必须严格依据 1992 年原始影像及历史对照地图判读，**严禁使用现代高清底图推定 1992 年地类**。
   - 2021 年样本主要基于 2021 年 Landsat 8 影像及同期参考资料。
2. **纯像元与缓冲区原则：**
   - 多边形边界距地类边缘至少向内缩进 15 米（半个像元），避开道路边缘、水陆交界、线状树木等混合像元。
   - 严禁在云、阴影、传感器条带噪声或明显受污染区域标注样本。
3. **多波段与指数协同验证：**
   - 判读建设用地时，应同步叠加 NDBI 与 BSI 辅助验证。
   - 判读细小水体时，结合 MNDWI 阈值确认水面边界。
4. **全过程记录：**
   - 标注完成后，由样本负责人 B 编写 `reports/accuracy/sampling_{year}.md`，记录各类别地块分布、代表性说明及核查证据。
