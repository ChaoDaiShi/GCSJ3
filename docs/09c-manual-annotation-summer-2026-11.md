# 新都区地类样本人工标注操作手册（2026-11 版）

**用途**：指导标注人员用 QGIS 在 1992 年与 2021 年影像上重新绘制四类地类样本，替代此前由光谱阈值自动筛选的候选面，使两期分类口径一致、面积结论可交付。

**适用对象**：本项目组成员，会基本电脑操作即可，无需 GIS 经验。

**总用时**：单年约 60 分钟（准备 15 分钟 + 绘制 35 分钟 + 校验导入 10 分钟）。

---

## 一、先搞清楚要做什么

### 1.1 背景

项目早期为了赶进度，用「NDVI < 0.40 且 NDBI > −0.10」这类光谱阈值自动圈出候选面当训练样本。实验证明这条路走不通：

| 问题 | 现象 |
| --- | --- |
| 样本是光谱极值 | 模型只认识最纯的硬化地，建成区面积被压扁到实际的三分之一 |
| 两期口径不一致 | 1992 年同判据只能圈出 1.38 km²，2021 年圈出 9.74 km²，变化量成为伪信号 |
| 精度虚高 | 标注和验证同源，OA 冲到 0.99，没有意义 |

所以改为**人工判读**：由人对照影像，判断「这块地是什么」，画成面。这是唯一能得到可信面积的办法。

### 1.2 这次要画多少

| 类别 | 编号 | 每期数量 | 单面面积 | 合计面积参考 |
| --- | ---: | ---: | --- | ---: |
| 城镇及建设用地 | 1 | 12 个 | 3—80 ha | 60—120 ha |
| 耕地 | 2 | 12 个 | 10—60 ha | 150—400 ha |
| 林草植被 | 3 | 12 个 | 3—40 ha | 40—100 ha |
| 水体 | 4 | 已预填 8 个 | — | 70—80 ha |

两期（1992、2021）各画一套，共 72 个面。水体不用画。

### 1.3 交付什么

| 交付物 | 位置 |
| --- | --- |
| 2021 年标注图层 | `data/samples/2021/annot_2021_c*.gpkg` |
| 1992 年标注图层 | `data/samples/1992/annot_1992_c*.gpkg` |
| 校验报告（屏幕输出） | 运行 `validate_annotations.py` 后复制给我 |
| 标注说明（画了哪些、为什么） | 口头说明或写在各面 `note` 字段 |

## 二、准备环境（约 15 分钟，只做一次）

### 2.1 确认软件

| 软件 | 版本 | 位置 |
| --- | --- | --- |
| QGIS | 3.44 LTR | `D:\Program Files\QGIS 3.44.15` |
| Python 环境 | rs-city（micromamba） | `F:\rs-tools\envs\rs-city` |

QGIS 只需要图形界面，不用装插件。如果 QGIS 打不开，先找项目负责人，不要自己重装。

### 2.2 新建工程并设置坐标系

1. 打开 QGIS，菜单 **工程 → 新建**；
2. 菜单 **工程 → 属性 → 常规**，确认「工程坐标系」显示 `EPSG:32648 - WGS 84 / UTM zone 48N`；
   如果不是，点右侧「过滤」输入 `32648`，选中后确定；
3. 菜单 **工程 → 另存为**，保存到 `E:\工程实践3\GCSJ3\qgis\annotation_2021.qgs`。

**为什么要确认坐标系**：项目所有数据都是 UTM 48N 投影坐标，单位是米。坐标系错了，画出来的面会偏移几十公里，后面全部作废。

#### 找不到 EPSG:32648 怎么办

QGIS 3.44 的中文界面里，这个坐标系的名字显示为 **「WGS 84 / UTM zone 48N」**，前面不带 EPSG 编号，很容易漏看。按下面顺序排除：

1. **用编号搜**：在坐标参考系统页顶部的「过滤」框里只输入 `32648`（不要输 `EPSG:32648` 全称），列表会只剩一条，右侧「标识」显示 `EPSG:32648`；
2. **按树找**：展开「投影坐标系(Projected)」→「UTM」→「WGS 84」→「Northern Hemisphere（北半球）」→ 选 `WGS 84 / UTM zone 48N`。
   **注意选带 N（北半球）的那个**，列表里还有 `zone 48S`（南半球），选错会偏到南太平洋；
3. **让数据自己带**：先加载 `outputs/rasters/xindu_2021_truecolor_30m.tif` 或 `data/processed/boundaries/xindu_2021.gpkg`（这两个文件本身就是 32648），QGIS 默认会把工程 CRS 设成第一个图层的 CRS，通常不需要手动设；
4. **手动指定来源**：工程属性 → 坐标参考系统 → 点「过滤」框右侧的下拉按钮，选「从图层设置」，再选已加载的影像或边界图层。

**怎么确认设对了**：看窗口**右下角**，应显示 `EPSG:32648`；把鼠标移到影像上，底部状态栏的坐标应是 `400000, 3400000` 这种七位数（米），如果显示 `104.1, 30.8`（度），说明还是地理坐标系 EPSG:4326，必须改。

**为什么要确认坐标系**：项目所有数据都是 UTM 48N 投影坐标，单位是米。坐标系错了，画出来的面会偏移几十公里，后面全部作废。

### 2.3 加载底图（真彩色影像）

1. 菜单 **图层 → 添加图层 → 添加栅格图层**（或按 `Ctrl+Shift+R`）；
2. 点右上角「…」浏览到：
   `E:\工程实践3\GCSJ3\outputs\rasters\xindu_2021_truecolor_30m.tif`
3. 确定。

加载后应看到彩色影像（绿色农田、灰白城区、深色水面）。**如果显示成黑白**，右键该图层 → **属性 → 符号化**，将「渲染类型」从「单波段灰色」改为「多波段彩色」，把红色/绿色/蓝色分别设为 `red`/`green`/`blue`。

> 1992 年换用 `xindu_1992_truecolor_30m.tif`，操作完全相同。

### 2.4 加载四个标注图层

1. 菜单 **图层 → 添加图层 → 添加矢量图层**（`Ctrl+Shift+V`）；
2. 一次性选中这四个文件（按住 `Ctrl` 多选）：

```
E:\工程实践3\GCSJ3\data\samples\2021\annot_2021_c1_urban.gpkg
E:\工程实践3\GCSJ3\data\samples\2021\annot_2021_c2_crop.gpkg
E:\工程实践3\GCSJ3\data\samples\2021\annot_2021_c3_forest.gpkg
E:\工程实践3\GCSJ3\data\samples\2021\annot_2021_c4_water.gpkg
```

3. 确定。图层列表里会出现 4 个图层，名字带 `labels_edit`。

> 这四个图层就是「画布」，**一类一个**。画在哪层，这个面就算哪一类，不需要填任何属性字段。

> 三个空图层（城镇/耕地/林草）的几何类型是 Polygon，打开后「符号化」页面有正常的符号设置。若页面空白，说明加载到的是旧版本图层文件（几何类型未知），在图层列表右键删除后重新拖入即可。

### 2.5 加载参考边界

再添加两次矢量图层，同一个文件的两个图层：

```
E:\工程实践3\GCSJ3\data\processed\boundaries\xindu_2021.gpkg
```

第一次选 `study_area`（研究区边界），第二次选 `townships`（9 个街镇边界）。建议：

- `study_area`：只留边界线，填充设为「无填充」，线宽 0.6；
- `townships`：无填充，线宽 0.3，颜色灰色，并把图层名标注打开（方便知道自己在哪个镇）。

### 2.6 给四个标注图层上色

对每个标注图层重复：

1. 右键图层 → **属性**（或双击）；
2. 左侧选 **符号化**；
3. 顶部「符号」下拉保持「单一符号」；
4. 点下方颜色块 → 选颜色；
5. 把「不透明度」调到 **40%** 左右（关键：调太高会挡住底图，看不出地物）；
6. 确定。

推荐配色：

| 图层 | 颜色 | 说明 |
| --- | --- | --- |
| `annot_2021_c1_urban` | 橙色 `#D95F02` | 与最终制图一致 |
| `annot_2021_c2_crop` | 黄色 `#E6C84F` | |
| `annot_2021_c3_forest` | 绿色 `#2E8B57` | |
| `annot_2021_c4_water` | 蓝色 `#377EB8` | 已预填 8 个面，只需确认 |

### 2.7 保存工程

**工程 → 保存**（`Ctrl+S`）。之后每次画完也保存一次。

## 三、画之前：怎么判断地物

### 3.1 用真彩色判读

| 类型 | 影像特征 |
| --- | --- |
| 城镇 | 灰白/浅灰屋顶，成片，有网格状道路，厂房是大块浅色矩形，工地是裸土色并带规则边 |
| 耕地 | 规则矩形，田埂笔直、颜色随作物变化（水稻浅绿、旱作黄绿、收割后褐），成片连续 |
| 林草 | 不规则边界，深绿且纹理粗糙，多在坡地、河岸、村庄周边（川西林盘） |
| 水体 | 深蓝/近黑，边界平滑，河渠呈线状 |

### 3.2 用工具辅助判断

**① 识别像元值**：菜单 **视图 → 识别要素**（`Ctrl+Shift+I`），点影像上任意位置，弹出面板会显示该处 NDVI、NDBI 等值。

经验值（7—8 月影像）：

| 地物 | NDVI | NDBI |
| --- | ---: | ---: |
| 城镇 | 0.10—0.30 | −0.05—0.15 |
| 耕地 | 0.55—0.70 | −0.30——0.20 |
| 林草 | 0.70—0.85 | −0.45——0.30 |
| 水体 | 0.10—0.30 | 负值 |

这些只作参考，**最终以目视为准**，因为带树的城区 NDVI 可以到 0.4，苗木基地 NDVI 也接近林地。

**② 看历史影像对比**：右键底图 → **属性 → 信息**，能看到成像日期。2021 年用 7 月 31 日，1992 年用 8 月 16 日。

**③ 缩放**：滚轮放大到 1:5000—1:10000（右下角会显示比例尺）最合适，太大看不清结构，太小定不准边界。

## 四、正式绘制（主体工作，约 35 分钟）

### 4.1 通用操作（每个面都一样的四步）

1. **选图层**：图层列表点选目标类图层（例如 `annot_2021_c1_urban`）；
2. **进编辑**：工具栏点铅笔图标（**切换编辑模式**，`Ctrl+E`）。图层名右侧出现小铅笔即成功；
3. **画多边形**：点 **添加多边形要素** 图标（工具栏里带绿色加号的多边形，快捷键 `Ctrl+.`）；
   - 沿边界逐点左键单击；
   - 画完右键单击结束；
   - 弹出「要素属性」对话框，直接点 **OK**（`note` 可填可不填）；
4. **保存**：点 **保存图层编辑**（软盘图标，`Ctrl+S`），再点铅笔退出编辑。

> 重要习惯：**画 3—5 个面就保存一次**。QGIS 崩溃不会自动保存。

### 4.2 画城镇（12 个，分三种形态）

要求三种形态都要有，否则模型学不到差异：

| 形态 | 数量 | 单面面积 | 特征 | 推荐位置 |
| --- | ---: | --- | --- | --- |
| 老城连片 | 4 个 | 20—80 ha | 密集屋顶、老街巷、商业区 | 桂湖街道（老县城）、新都街道 |
| 工业园 | 4 个 | 15—60 ha | 大块厂房、仓库、堆场 | 新繁街道、石板滩街道、斑竹园街道 |
| 乡村居民点 | 4 个 | 3—10 ha | 小片院落、村道两侧 | 军屯镇、清流镇、新民（属新繁） |

操作要点：

- 工业园画**厂区主体**，不要把配套绿地和道路并进来；
- 乡村居民点画**建筑密集的那一小片**，不要画整个村域（村域里大部分是耕地）；
- 老城连片可以画得大一些，但**单个面不超过 100 ha**，太大就拆成两个。

### 4.3 画耕地（12 个）

要求：

- 单面 10—60 ha，边界沿**田块外沿**走，不要顺着一块田的中间切；
- 优先选**纯旱作或纯水稻**的连片区域，避免「水稻+苗木+村庄」混杂的地块；
- 尽量落在平原区：斑竹园、军屯、清流、新繁、新民一带；
- 12 个面分散到**至少 4 个街镇**，不要全在一个镇。

操作要点：

- 田块多为矩形，按住 `Shift` 可以画直线段，边界更贴合；
- 如果一大片田有几十公顷，画其中**边界清晰的一段**即可，不必画满。

### 4.4 画林草（12 个）

要求：

- 单面 3—40 ha；
- 优先选**坡地林地、成片果园、河岸林带、川西林盘**；
- 分布参考：石板滩街道东部浅丘、三河街道、木兰（属新都街道北部）、毗河沿岸；
- 不要画行道树、公园草坪、单排树带（面积太小、边界不稳）。

操作要点：

- 林盘边界不规则，用**顶点工具**（工具栏箭头旁的下拉，选「顶点工具」）微调，比重新画快；
- 与耕地交界处，宁可**少画一点**，也不要越界到田里。

### 4.5 确认水体（8 个已预填）

水体图层已有 8 个面，来自上一轮人工标注，精度可靠（F1 0.96 以上）。

只需做一件事：打开图层，逐个看一遍，确认它们**仍然落在水体上**。若某个面明显错位（比如压到岸上），用顶点工具修正或删掉重画。

如果发现研究区内有明显的大水面没被覆盖（例如新建的人工湖），可以补 1—2 个，但**总数不超过 12 个**。

打开 PowerShell，进入项目目录：

```powershell
cd E:\工程实践3\GCSJ3
```

### 5.2 看懂输出

正常输出类似：

```
=== 1 城镇及建设用地：12 个面，合计 78.4 ha ===
  面积 min 3.42 / 中位 18.20 / max 62.10 ha
  覆盖街镇 5 个

=== 2 耕地：12 个面，合计 246.8 ha ===
...

================ 校验结果 ================
[警告] 城镇及建设用地：2 个面的 NDVI 均值超出 [0.0, 0.45]
通过：可以导入
```

### 5.3 什么必须改

| 输出 | 含义 | 处理 |
| --- | --- | --- |
| `[错误] 只有 N 个面，至少需要 8 个` | 数量不够 | 补画到 12 个 |
| `[错误] N 个面小于 2.0 ha` | 面太小 | 扩大或删掉重画 |
| `[错误] A 与 B 有重叠 XXXX m²` | 两类画到同一块地 | 删掉其中一个 |
| `[警告] NDVI 均值超出 [...]` | 该面光谱与类别不符 | 看一眼影像，确认画错就改，画对就忽略 |
| `[警告] 只覆盖 N 个街镇` | 分布太集中 | 挪几个面到别的镇 |

**只要有「[错误]」，不要去导入**，改完重新校验，直到显示「通过：可以导入」。

## 六、导入并重跑（10 分钟）

### 6.1 导入标注

```powershell

```

脚本会做四件事：

1. 把 4 个图层合并成正式标签 `data/samples/2021/labels.gpkg`；

预期输出：

## 八、常见问题对照

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 画完看不到面 | 图层顺序在底图下面 | 图层列表把标注层拖到最上面 |
| 面是实心挡住影像 | 不透明度太高 | 属性 → 符号化 → 不透明度调 40% |
| 属性表里没有新面 | 画在了别的图层 | 检查图层列表哪个是选中状态 |
| 保存后重开没了 | 没点保存图层编辑 | 画完必须点软盘图标 |
| 面跑到海里/国外 | 工程坐标系错 | 工程属性改回 EPSG:32648 重画 |
| 校验说面积 0 | 面自相交（画成 8 字形） | 删掉重画，按顺序点边界 |
| 「符号化」页面一片空白 | 空图层的几何类型未知（旧文件） | 图层列表右键删除该层，重新拖入 gpkg；或直接画第一个面后符号设置就会出现 |
| 导入报「没有任何面」 | 图层没保存 | 回到 QGIS 保存后重试 |
| 重跑报 `Pixel assigned to multiple` | 两类样本重叠 | 跑校验，删掉重叠的面 |
