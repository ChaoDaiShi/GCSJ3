# 手工标注作业单（4 类 × 8 组 × 2 年 = 64 个组）

> 配套文件：`docs/sample-group-plan.csv`（64 行编号表，可直接对照着填）
> 目标文件：`data/samples/2021/labels.gpkg`、`data/samples/1992/labels.gpkg`（空模板已建好，图层名都是 `labels`）

**总工作量**：64 个组，每组画 1 个面（个别地块被路切开可画 2 个面共用一个组号）。
2021 约 80—100 分钟，1992 约 100—120 分钟。

---

## 一、开工前 4 件事（各 1 分钟）

1. 启动 QGIS，左侧「浏览器」展开 `outputs/rasters/display`，双击
   `xindu_2021_truecolor_15m_rgb.tif`、`xindu_2021_falsecolor_30m_rgb.tif`（两张都加，互相验证）；
2. 浏览器展开 `data/samples/2021/labels.gpkg` → 双击 `labels`；
3. 选中 `labels` 图层 → 点铅笔（切换编辑模式）；
4. 打开菜单 `设置 → 选项 → 数字化`，勾上「**复用上次输入的属性值**」。

> 底图是已经拉伸好的 8 bit RGB，打开就是正常颜色，**不用再设拉伸**。

---

## 二、画一个组的固定动作（6 步，约 90 秒）

1. 缩放到 **1:25,000** 左右（右下角比例框输入 `25000` 回车）。这个比例下 150 m 的地块在屏幕上约 6 mm，正好画；
2. 找一个 ≥150 m 见方的同类地块（判据见第三节）；
3. 工具栏「**添加多边形要素**」→ 沿地块内缘逐点点击 → **右键**闭合；
4. 弹窗填 4 个值（其余靠「复用上次值」自动带）：

   | 字段 | 填什么 |
   | --- | --- |
   | `sample_id` | 照 CSV 抄，如 `2021_c1_g01_p01` |
   | `group_id` | 照 CSV 抄，如 `c1_g01` |
   | `year` | `2021` |
   | `class_id` | `1`（看 CSV 的 class_id 列） |

   另外三个（`label_source`=`manual_2021`、`source_date`=`2021-02-05`、`annotator`=你的名字）第一次填完，后面就自动复用。

5. 点数字化工具栏的「**保存图层编辑**」软盘图标保存（Ctrl+S 只存工程，不存图层编辑）；
6. 在 CSV 的 `done` 列打个勾，画下一个组。

> 同一类连着画 8 个组时，`class_id` 和 `label_source` 完全不用改，只有 `group_id` / `sample_id` 要换号。这就是为什么建议**按类集中画**。

---

## 三、每类去哪儿找、怎么认（对着 1:25,000 看）

### 1 城镇及建设用地（8 组）

- **真彩色里**：灰白、浅灰、青灰的连片硬质地表，轮廓方正，有成排的"条状"（厂房）或密集小格（居民区）；
- **扫图路线**：先看**中部偏南**的城区（最明显的一大片灰白），画 3 个组（互相隔 ≥300 m）；再往**西/北**找镇区、往**南**找大丰一带的厂房园区，各画 2—3 个组；
- **别画**：村庄边缘（半树半房）、单栋小楼、田里的小机耕道。

### 2 耕地（8 组）

- **真彩色里**：成片的方格/长条田块，颜色偏浅绿、灰绿、土黄，田埂形成规律网格；
- **假彩色里**：田块呈**整片均匀的红**或粉色（2021 年 2 月休耕偏灰红）；
- **扫图路线**：城区外围的大片方格区就是；优先挑**田块完整、面积 ≥2 公顷**的地方，每个组隔开几百米；
- **别画**：田块中间夹着村庄/林带的面；形状破碎、宽不到 3 个像元（90 m）的窄条。

### 3 林草植被（8 组）

- **假彩色里**：**深红、暗红**，质地粗糙（不是田块那种平整的红）；
- **真彩色里**：深绿成片、边界不规则；
- **扫图路线**：沿河两侧的林带、公园绿地（成片树冠）、西/北方向的丘陵林地、成规模的苗圃；
- **别画**：行道树、房前屋后几棵树、林盘边缘半树半房的地方。

### 4 水体（8 组）

- **假彩色里**：**深蓝到近黑**、连续、边界平滑；
- **真彩色里**：深蓝绿、暗色条带；
- **扫图路线**：找贯穿全区的**主干河道**（东西向的长条），沿河道选 4 个相隔较远的组；再找**成片鱼塘/坑塘群**（密集的小方块或圆块），选 4 个组；
- **别画**：田沟、宽度不足 3 个像元的细渠、长满水草的浅塘（颜色偏绿）。

---

## 四、8 个组怎么摆才合格（这是评审会看的）

1. **同类的 8 个组要分散**：别全挤在一个片区，至少覆盖 3—4 个镇街（打开 `镇街边界` 图层对照）；
2. **组与组之间至少隔 300 m**（约 10 个像元）。挨在一起等于一组；
3. **一个组可以含多个面**（同一地块被路切开的），它们 `group_id` 相同、`sample_id` 用 `_p01`、`_p02` 区分；
4. **面与面不能重叠**（重叠会让同一像元被算两次，代码报错）；
5. **面不要压到云、云影、研究区外的黑边**。

## 五、画完自检（3 分钟）

**QGIS 里**：右键 `labels` → 属性表 → 看行数是否 = 32（每类 8 个），`class_id` 是否只有 1—4。

**命令行**（QGIS 先保存、关闭）：

```powershell
cd 'E:\工程实践3\GCSJ3'
. .\activate-rs-city.ps1
python -X utf8 -c @'
import geopandas as gpd
g = gpd.read_file(r"data\samples\2021\labels.gpkg", layer="labels")
print("CRS:", g.crs, "| 面数:", len(g))
print(g.groupby("class_id")["group_id"].nunique())
print("组跨类别冲突:", int((g.groupby("group_id")["class_id"].nunique() > 1).sum()))
'@
```

合格：`EPSG:32648`、每类 8、冲突 0。

## 六、经常卡住的地方

| 卡在哪 | 怎么办 |
| --- | --- |
| 找不到"添加多边形要素" | 必须先点铅笔进编辑模式，工具栏才出现要素工具 |
| 画完没弹属性窗 | 右键闭合后才会弹；或按 `F2` 闭合 |
| 属性窗关掉了 | 按 `Ctrl+K`（打开属性面板），或 `视图 → 面板 → 激活捕捉面板` 旁找「属性」 |
| 底图全黑 | 用了 `outputs/rasters` 里的原始 file；改用 `outputs/rasters/display` 里的 |
| 面看不见（被底图盖住） | 图层面板把 `labels` 拖到最上层 |
| 保存后重开没有面 | 按了 Ctrl+S（只存工程），没点「保存图层编辑」软盘。退出编辑模式时会弹「是否保存图层编辑」——选保存 |

## 七、想更快：直接复用候选面

`data/samples/{year}/labels_candidates.gpkg` 里已有每类 15 个机器候选面（共 60 个/年）。你完全可以：

1. 打开候选图层，看中哪个是对的；
2. 用「选择要素」选中它 → `编辑 → 复制要素` → 选中 `labels` 图层 → `编辑 → 粘贴要素`；
3. 粘贴后把 `sample_id` / `group_id` 改成你 CSV 里的编号，`label_source` 改成 `manual_2021`；
4. 不对的面不要用，自己画。

这样能省掉"画边界"的时间，但**每个面仍然要你自己看一眼判断**——这一点不能省。
