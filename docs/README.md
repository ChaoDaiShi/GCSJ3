开始开发时先读设计、契约和并发计划。取数人员重点读数据目录；环境准备人员重点读环境说明；验收人员以验收矩阵为准。

文档使用 `P0`—`P3` 表示**第一阶段内部的开发批次**。它们不是四个额外产品阶段。`P1-A`—`P1-F` 是可并发工作线，`P2` 的工作在其依赖满足后即可开始，无需等待所有 `P1` 任务结束。

未来第二阶段只考虑首版验收后的优化，如增加时相或对照模型；本轮不为这些内容开发代码。
