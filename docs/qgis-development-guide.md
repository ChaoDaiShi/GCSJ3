## 1 项目目标与阅读方式
本开发文档把《工程实践3 总体设计方案（第5组）》落实为可分工、可联调、可复跑的 QGIS 开发方案。研究对象为成都市新都区 1992 年与 2021 年土地覆被及遥感建设用地扩张。首版延续既有“不引入插件架构”的边界：保留离线分析核心，开发可复现工程构建脚本、QML 样式、QPT 布局、样本表单配置、检查与导出脚本。

本开发文档中的“已存在”仅表示仓库中有源码或规范，不代表本次环境运行通过；“新增设计”须实现并通过验收后才能宣称可用。示例、合成测试数值和拟新增命令不是新都区真实结果。进度为相对工作日，不承诺未经确认的日历截止日期。本轮仅开展只读审计和文档设计，未运行项目测试、未验证用户本机外置成果。

## 2 科学需求与质量基线

### 2.1 必须保持一致的研究口径
| 编号 | 需求 | 验收证据 |
| :--- | :--- | :--- |
| **SCI-01** | 1992 Landsat 5 TM 与 2021 Landsat 8 OLI 分年标注、训练、验证 | catalog、样本、split、模型元数据 |
| **SCI-02** | 统一 EPSG:32648、30 m，固定 bounds、transform、width、height | grid.json 与逐文件网格检查 |
| **SCI-03** | 城镇及建设用地 1、耕地 2、林草植被 3、水体 4；分类 0 仅为 NoData | 类别表、栅格唯一值、颜色与图例 |
| **SCI-04** | 六个 SR 波段加 NDVI、NDBI、MNDWI、BSI，顺序固定 | 配置、band description、模型特征顺序 |
| **SCI-05** | 按类对唯一地块组分层分组，25% holdout；每类至少 8 组、holdout 至少 2 组 | split.json、组与像元交集检查 |
| **SCI-06** | 两期 final OA 必须严格大于 0.75；建设用地 F1 目标不低于 0.75 | 独立评价报告与未舍入数值 |
| **SCI-07** | 只在两期共同有效区比较；区外 255 不得作真值 | mask==1 的实现与反例测试 |
| **SCI-08** | 街镇采用 2021 年边界，边缘像元按几何相交面积分摊 | 边界版本、叠加检查与面积平衡 |
| **SCI-09** | 样本、模型、配置、软件、输入及结果可追溯 | manifest、SHA256、Git 提交号、日志 |

### 2.2 类别边界
城镇及建设用地包含可辨识的城乡建筑、工业用地、道路、其他硬化地表及在建待建裸土。耕地与林草植被按冻结的解译手册区分，不能只依 NDVI 阈值代替人工判读。两期影像季节差异必须列入不确定性说明，不把光谱变化自动认定为土地变化。
目标日期优先核查 1992 年 8 月 16 日、2021 年 2 月 5 日；它们不是已核验下载成功的场景承诺。数据负责人须以 product_id、MTL、实际成像日期、覆盖和云情况确认能否采用；替换日期须说明理由与可比性影响。

### 2.3 门禁语义
OA 是强制门槛，等于 0.75 仍失败；F1 是总体方案给出的目标，不得擅自写成同等级硬门槛。若 OA 通过但建设 F1 未达目标，报告须突出风险，并由验收负责人决定是否要求补充调查，不得隐藏该项。正式指标以原始小数比较，显示百分比仅在报告层舍入。

## 4 总体架构与运行边界

```
[ 输入与冻结配置 ] ──> [ 离线科学计算环境 ] ──> [ 正式数据与证据 ]
(影像/边界/labels/split)   (src/01~05 既有CLI)       (栅格/矢量/CSV/精度)
                                                        │ 只读接入
                                                        ▼
[ 版本化模板 ] ──────> [ QGIS 工程构建脚本 ]
(QML/QPT/表单规则)       (路径预检→图层→样式→表单→统计关联→布局)
                                │
                                ▼
                       [ 候选 .qgz 与清单 ]
                       (真加载/路径/字段检查)
                                │ 校验通过
                                ▼
                       [ 正式交付包 ]
                       (工程/四图/日志/手册)
```

### 4.1 单一算法与单一数据来源
五个既有 CLI 负责遥感处理与计算。QGIS 构建脚本读取配置、正式成果及检查报告，组装图层、样式、表单、统计连接和布局。QGIS 不重新计算指数或街镇面积，不更改训练/留出划分。离线输出尚不完整时可生成明确标记的开发工程，但不得将其记作正式交付通过。

### 4.2 两套环境隔离
QGIS 使用安装包自带 Python、PyQt、GDAL；离线 rs-city/Conda 环境运行 Rasterio、GeoPandas、scikit-learn 等核心。通过文件契约对接，不将 Conda site-packages 插入 QGIS sys.path。PyQGIS 使用 qgis.PyQt；项目、图层与布局操作在 QGIS 主线程完成。构建脚本可由 QGIS Python 控制台调用，独立无界面运行另设经验证的启动器。

### 4.3 构建与提交顺序
读取只读配置 → 解析实际数据根 → 预检所有必需输入 → 创建候选 QgsProject → 加载图层和统计连接 → 应用样式与表单 → 装配四个布局 → 校验 → 写入同目录临时工程 → 重新打开验证 → 原子提交正式工程与清单。正式工程只引用通过门禁的产物，不靠文件存在就认定成功。

### 4.4 并发边界
开发时可并行编写加载器、样式、表单、布局与测试；整合工程由一个构建脚本串行生成。禁止多人同时编辑同一 .qgz 或同一 GPKG。两期计算可按资源预算并行，但变化阶段必须等待两个 final 和科学门禁，地图阶段必须等待对应真实产物。

### 4.6 路径来源
核心按进程环境变量优先于 `.env`、再优先于默认值解析目录；相对路径以仓库根为基准。QGIS 只读配置解析应复现该规则，支持 `RS_DATA_ROOT`、`RS_OUTPUT_ROOT`、`RS_REPORT_ROOT`，不固定假设每个成果都在 `../data`。解析结果先打印给用户核对，再相对工程位置写入数据源。
环境探针记录 Python 可执行路径、Python、QGIS、Qt、GDAL、PROJ 及实际 Processing provider；离线探针另记录 NumPy、scikit-learn、Rasterio。原方案建议 Python 3.11，但不能据此推断 QGIS 内置 Python 也是 3.11。验证中文/空格路径、GeoTIFF/GPKG/SHP、坐标转换和可写输出根。

## 5 输入目录与公共网格契约

### 5.1 目录登记
场景登记保留既有表头 `year`, `sensor`, `processing_level`, `product_id`, `acquisition_date`, `wrs_path`, `wrs_row`, `scene_dir`, `mtl_path`, `paired_product_id`, `source_url`, `downloaded_at`, `selection_status`。反射率、QA_PIXEL、QA_RADSAT 与 MTL 必须来自匹配产品；L1 展示与 L2 定量产品的关联单独核验。hash、云量和产品集合等补充信息写入来源报告，不静默替换已有列名。
边界 catalog 保留 `dataset_id`, `reference_year`, `admin_level`, `file_path`, `layer_name`, `source_crs`, `source_url`, `acquired_at`, `license_note`, `verification_status`；这与 GPKG 的行政字段不同。study_area 至少含 area_id/name/reference_year，townships 含 unit_id/name/unit_type/reference_year。unit_id 为保留前导零的稳定字符串，不能用中文名称作连接键。检查无效/空几何、重复 ID、重叠与缝隙。

### 5.2 公共网格
既有 `data/processed/grids/grid_30m.json` 使用整数 `schema_version=1` 和 GDAL 六项 transform 顺序。以投影后研究区范围向外按 30 m 取整，两个年份引用同一文件。15 m 网格复用同 bounds、宽高各两倍。
```json
{
  "schema_version": 1,
  "crs": "EPSG:32648",
  "resolution": [30, 30],
  "bounds": ["xmin", "ymin", "xmax", "ymax"],
  "transform": ["xmin", 30, 0, "ymax", 0, -30],
  "width": "positive integer",
  "height": "positive integer"
}
```
Rasterio 读取时必须用 `Affine.from_gdal(*transform)`，不能直接当作 `Affine(a,b,c,d,e,f)` 顺序。检查实际栅格头与冻结网格，不能只信旁车。新增 grid_id、边界 hash 等放扩展元数据或 manifest；未评审迁移前不得改变既有 JSON schema 或用字符串 1.0 替代整数 1。

### 5.3 边缘像元
`aoi_30m` 是 Byte，区内相交像元 1、区外 0；它服务于计算覆盖，不代表边缘像元全部属于行政区。样本提取采用像元中心落入样本面的规则；统计使用真实边界几何相交。三个规则用途不同，不能统一成一个 all_touched 开关。

### 栅格数据与掩膜契约
| 产品 | 类型与波段 | 无效值及核心校验 |
| :--- | :--- | :--- |
| `sr_30m` | Float32 ×6 | NoData=-9999；固定六波段顺序；公共网格 |
| `valid_sr_30m` | Byte ×1 | 1 有效、0 区内无效、255 区外；NoData=255 |
| `aoi_30m` | Byte ×1 | 1 区内相交、0 区外；单独定义，不沿用三态掩膜 |
| `features_30m` | Float32 ×10 | NoData=-9999；任何维无效则整向量无效 |
| `lulc_raw_30m` | Byte ×1 | 0 NoData；有效类别仅 1 至 5 |
| `lulc_final_30m` | Byte ×1 | 0 NoData；有效范围须与 raw 完全相同 |
| `valid_common_30m` | Byte ×1 | 1 共同有效、0 区内任一期无效、255 区外 |
| `change_1992_2021_30m` | Byte ×1 | 0 NoData；1 持续建设、2 新增、3 减少、4 持续非建设 |
| `pan_rgb_15m` | Float32 ×3 | NoData=-9999；TOA；仅展示，不要求 30 m 网格 |

### 5.4 统一判定而非布尔强转
`valid_sr` 与 `valid_common` 的有效条件恒为 `mask == 1`。`bool(255)` 为真，直接把三态掩膜转成 bool 会把区外算进去，必须有专门反例测试。分类有效条件为 `aoi==1` 且 `class ∈ {1,2,3,4,5}`；发现 6、255 或负值时报告契约错误，不能静默当作其他地类。
连续 SR 重投影使用双线性；QA、掩膜和分类使用最近邻。源网格先标记无效并为重投影设置 src_nodata，避免云与填充值污染连续插值。重投影后要求掩膜为 1 且所有所需波段为有限非 NoData 数值；不能仅靠掩膜证明有效。

### 5.5 文件完整性新增验收要求
本节的 partial/旁车/原子提交是增量设计，现有 CLI 尚无完整实现。过渡期由外部预检和 manifest 核验现有产物；不能因其缺少拟新增旁车就误称已违反旧契约。新增字段与 hash 规则由 W02/W21 统一实施。
GeoTIFF 写入 CRS、transform、NoData、band descriptions 和来源元数据；建议分块与压缩，但压缩参数不能改变数值精度。输出先写 `<name>.partial`，再关闭句柄、重新打开并校验，最后提交为正式文件。旁车 JSON 记录内容 hash 与 grid_id。缺少旁车或校验失败的文件不进入缓存命中，也不进入下游自动发现。

## 6 样本和独立验证契约

| 字段 | 类型与约束 | 用途 |
| :--- | :--- | :--- |
| `sample_id` | 字符串，年度内唯一 | 标识样本面，不随几何编辑重复 |
| `group_id` | 字符串，年度内稳定 | 同一真实地块的面共享，作为划分单位 |
| `year` | 整数，仅 1992 或 2021 | 阻止跨年混用 |
| `class_id` | 整数，1 至 5 | 与统一编码表匹配 |
| `class_name` | 由 class_id 派生 | 不允许用户自由录入不一致名称 |
| `label_source` | 字符串，必填 | 判读影像或辅助资料证据 |
| `interpreter` | 角色或成员标识，必填 | 标注责任，不公开不必要个人信息 |
| `confidence` | 冻结枚举 high/medium/low | 低置信度须复核，枚举属新增接口约定 |
| `notes` | 字符串，可空 | 争议、边界与特殊情况 |

以上为最新总体设计字段。现有仓库必需字段还包括 `source_date`, `annotator`, `split`，未直接采用全部新增字段。P0 必须保留原字段，明确 `interpreter` 与 `annotator` 映射，`class_name` 由编码派生，`confidence`/`notes` 作为经批准的扩展；不可直接覆盖旧 GPKG schema。`source_date` 是历史判读时相证据，不能用当代在线底图当 1992 真值。

### 6.1 冻结顺序
先校验年度标签、几何和组内类别一致性，再按每个类别的唯一 group_id 采用固定种子的 GroupShuffleSplit，holdout 比例 25%。按得到的组列表分配样本面，再展开像元。每类至少 8 组且 holdout 至少 2 组；若组数或有效像元数不足，停止并补标，不静默降低要求。类别不一致的同一组先人工复核，不拆组规避检查。
train.csv 和 holdout.csv 均保留 year、sample_id、group_id、class_id、row、col、x、y 及十维特征。以 (year, grid_id, row, col) 检查重复像元；不同类别重叠像元视为冲突而不是“最后一个面覆盖”。两集合的组交集和像元交集都必须为空。

### 6.2 空间独立不只看 ID
同一地块改名仍可能泄漏，冻结前审查组间重叠、近邻和连续地块，输出分布图。缓冲隔离距离须在训练前定义，不因 holdout 分数改变。GroupShuffleSplit 不自动保证距离意义的空间独立。

### 6.3 样本版本与锁定
现有 split 保存组映射及 hash。新增旁车记录标签 hash、组列表、种子、比例、年份和修订理由。冻结后改标签须新建版本并使下游失效；禁止旧工程覆盖新标签，同一 GPKG 只允许一个写者。

### 模型和实验治理
### 6.4 模型元数据
既有模型路径为 `outputs/models/{year}/rf.joblib`，内容字典含 estimator、feature_names、class_codes、year、config、split_sha256。应保留兼容，新增 meta.json 可作为旁车，不擅自改为另一种 joblib 结构。新增旁车元数据至少含 model_id、year、algorithm、feature_order、class_codes、train_sha256、split_sha256、grid_id、params、random_seed、library_versions 和 created_at。加载前先核对文件来源与 hash，再校验特征顺序、年份、类别及版本兼容；不满足时拒绝推理，不自动排列未知列来“修复”。
```json
{
  "schema_version": "1.0",
  "algorithm": "random_forest",
  "year": 1992,
  "random_seed": 42,
  "feature_order": ["blue","green","red","nir","swir1","swir2","ndvi","ndbi","mndwi","bsi"],
  "params": {
    "n_estimators": 300,
    "min_samples_leaf": 2,
    "max_features": "sqrt",
    "class_weight": "balanced_subsample"
  },
  "train_sha256": "<sha256>",
  "split_sha256": "<sha256>"
}
```

### 6.5 开发集与最终留出集
训练模块只能读取 train.csv。调参、特征选择、SVM/纹理/RFE 等研究在训练组内部再做分组交叉验证；训练折内拟合所有数据驱动变换。最终 holdout 不参与筛样、阈值选择、模型排名或后处理参数搜索。RF 与最大似然基线的比较协议、参数和报告格式在最终评价前确定。
W17 先完成协议与报告程序，只有 W22 才在正式数据上读取最终 holdout；W21 用合成验证，不能提前消耗真实留出集。最终评价可在同一预先冻结的协议下同时报告 raw、final 及预定基线结果；它是一次评价批次，不是挑选最高分的机会。需提前明确最终主模型及 Sieve 参数，不依据 holdout 选择 raw 或 final 作为成果。

### 6.6 未达标后的合法路径
技术重试：磁盘、进程或导出故障导致未生成合法报告，可用相同输入、相同模型和相同配置重跑，记录 attempt，不改变研究选择。科学修订：看过 holdout 后修改样本、模型或特征，即进入新实验版本；原留出集已经提供信息，不能继续声称其为未触碰测试集。需在新的预注册协议下获取新的独立验证证据，或明确将旧分数作为探索性结果，并报告当前未通过正式验收。禁止无限重试直到“碰巧达标”。

### 7.6 表单与渲染细节
ValueMap 把 1 至 5 映射到中文类名；必填、唯一等约束用目标 QGIS 版本支持的 API 设置并测试。group_id 不能设置唯一约束，因为同一地块可有多个面。跨要素 group_id 同类、空间重叠、像元冲突不能只靠单字段表单约束，应由保存前/交接检查器验证。冻结 split 设置只读并保留原值。
样式加载不等于语义正确：检查分类代码与名称、颜色、NoData、渲染器类型。SR 使用波段名称映射 RGB，不把 TM 与 OLI 原始编号直接套到统一六波段栅格。统计强度图使用 annual_intensity_pct，分级方法和断点在比较前冻结，NULL 单元单独样式。CSV 通过 provider 类型约定或 .csvt 保持 unit_id 字符串，再验证真实读取类型。

## 8 构建状态与失败恢复

```
[ 未开始 ] ──> [ 预检 ] ──> [ 候选构建 ] ──> [ 待检查 ] ──> [ 正式通过 ]
                 │             │
                 ▼             ▼
             [ 缺项阻塞 ]   [ 构建失败 ]
（旧工程保持不变）
```

### 8.1 状态与门禁
- `NOT_STARTED`：尚未启动；
- `CHECKING`：正在预检；
- `BUILDING`：正在候选工程装配；
- `BUILT_PENDING_QA`：已写出但未验收；
- `PASSED`：完成全部检查；
- `FAILED`：存在技术错误；
- `BLOCKED`：缺输入或科学证据；
- `CANCELLED`：已停止且未提交正式产物。
任何一项不完整都不能以“QGIS 可以打开”代替最终通过。

### 8.2 失败与停止
本期构建脚本以分阶段检查和短步骤串行为主，不承诺既有 CLI 拥有实时进度或立即无损取消。长计算继续在独立终端运行。人工中断后必须确认进程结束、句柄关闭、检查受影响派生文件，并从完整上游重跑该阶段；不能直接续用半写文件。旧工程在候选成功提交之前保持不变。
构建器在输入缺失时先输出完整缺口列表，不边加载边忽略错误；图层失效、统计 join 不匹配、布局导出失败均写入报告。使用独立 QgsProject() 构建，不清空用户当前工程。候选文件置于正式工程同一目录，仅文件名不同；设置相对路径后保存，检查 write()，用另一个 QgsProject() 的 read() 真重读并关闭验证对象后再同盘 rename。若临时工程在不同目录，直接移动会改变相对路径基准，必须重建并在最终位置再次验证；多个配套文件使用候选目录加提交清单，不能误称跨盘移动原子。

### 8.3 恢复与重复执行
在相同输入、配置、样式和版本下，重复构建不产生重复图层、重复布局或重复 join。复用已存在工程须识别 logical_id 并显式替换受管对象；保留不属于构建器的用户内容前需有确定策略。首版建议每次从干净候选工程生成，避免累积状态。
恢复只复用 hash 和契约都匹配的完整上游成果。输入或 split 改变则下游失效，需创建新实验版本。清理只在任务专用临时目录进行，不删除原始数据、标签或其他运行的文件。可选自动任务与进程树取消的完整设计见附录 C，未批准前不列入当前能力。

## 9 QGIS 原生工作区与操作

### 9.1 用户工作流
用户打开工程后，左侧图层树按“边界／1992／2021／变化／统计／展示／样本”组织；中央为地图画布；属性表与表单使用 QGIS 原生停靠/窗口；右侧可打开统计与检查报告。操作入口采用文档化脚本与原生菜单，不新增自定义插件工作台。
首次使用：确认 QGIS 版本 → 设置数据和成果根 → 执行只读预检 → 构建开发工程 → 检查影像和样本 → 在外部环境执行既有算法 → 接入正式成果 → 打开布局管理器导出 → 运行检查并打包。构建脚本失败时保留旧工程，用户按错误报告定位文件。

### 9.2 项目视图
1992 与 2021 分组分别包含 SR、有效性、raw、final 和样本引用；默认显示 final，raw 关闭但可一键切换复核。变化组包含变化分类、共同有效范围和变化矢量；统计组包含街镇几何及属性连接。展示融合图单独命名“2021 15 m TOA 辅助判读”，不得混入定量图层。
缺测用透明、网纹或独立图例说明，与持续非建设区分。分类渲染用离散色表和最近邻显示，不用连续渐变或双线性渲染模糊类别。两期比较使用固定地图范围、相同类别顺序和样式。

### 9.3 易用性要求
表单字段按年度、类别、地块组、证据和备注组织，字段别名使用中文，解释通过提示提供。必填、范围与唯一性错误给出文字原因，不仅变红。长路径在检查报告可复制；所有警告能定位到图层和字段。冻结样本以只读方式呈现；未保存编辑在关闭工程前由 QGIS 提示，构建脚本不替用户强制保存。

### 页面字段与交互验收
### 9.4 样本表单字段控件
| 字段或操作 | QGIS 配置 | 校验规则 |
| :--- | :--- | :--- |
| `year` | 值映射或只读默认年度 | 与图层年份一致，禁止跨年混写 |
| `class_id` | 值映射 1 至 5 与中文类别 | 必填；类别表同配置 |
| `sample_id` | 唯一文本与默认生成策略 | 保存前唯一且非空 |
| `group_id` | 文本或已有组选择 | 必填；同组同类；同地块共用 |
| `label_source`/`source_date` | 文本及日期控件 | 证据来源及时相必填 |
| `annotator`/`interpreter` | 受控标识与映射 | 保留标注责任，不自由改旧版本 |
| `split` | unassigned/train/holdout 只读 | 由冻结结果派生，不手工挑选 |
| `confidence`/`notes` | 扩展控件，经迁移批准后启用 | 低置信复核；不改变旧必需字段 |

### 9.5 几何编辑语义
新绘面生成 sample_id，group_id 选择已有真实地块组或明确新建。拆分同一地块保留 group_id，为片段生成新的 sample_id；合并跨组面先复核是否同一地块，不自动取第一组。冻结 split 后的标签只读；修订另存新版本、记录理由并评估下游失效，不能原地改冻结文件。
保存前检查空/无效几何、同类与跨类重叠、重复像元、QA 覆盖和有效像元数。同一 GPKG 只允许一个写者；并行标注按事先分配的地块与独立工作文件进行，由 D 角色在交接后串行汇总，重复 ID 和重叠冲突必须人工处理。

### 9.6 统计关联
CSV 指定 UTF-8，unit_id 按字符串读入，保留前导零。关联前检查街镇和统计表 ID 各自唯一、覆盖匹配、无多对多；零匹配与多匹配均阻断正式工程。CSV 空指标保持 NULL，不以 0 填补缺测。类别名、面积单位与字段别名在样式/表单层展示，核心列名不随中文别名改变。

### 9.7 交互验收路径
打开指定年度样本 → 新建面并填字段 → 错误类别/空组号应被阻止 → 正确保存 → 拆分后检查组号不变 → 回滚未提交编辑 → 冻结后不能手工修改 split → 载入统计检查前导零 → 关闭并重开工程复核样式、表单及 join 保留。

## 10 预处理开发细则

### 10.1 辐射与 QA
Landsat Collection 2 Level-2 SR 使用统一比例因子，输出 Float32，NoData 为 -9999，不做未经说明的 0 至 1 截断。
$$SR = DN \times 0.0000275 - 0.2$$
TM 排除 Fill、Dilated Cloud、Cloud、Cloud Shadow、Snow；OLI 再排除 Cirrus。QA_RADSAT 只按选用反射波段的饱和位及对应传感器 dropped pixel/terrain occlusion 规则判断；不可把另一个传感器位表套用过来。Water 位不是剔除条件。位定义以 USGS 产品文档为准并实现成有名称的常量与单元测试。

### 10.2 波段映射
| 统一名称 | Landsat 5 TM | Landsat 8 OLI |
| :--- | :--- | :--- |
| `blue` | SR_B1 | SR_B2 |
| `green` | SR_B2 | SR_B3 |
| `red` | SR_B3 | SR_B4 |
| `nir` | SR_B4 | SR_B5 |
| `swir1` | SR_B5 | SR_B6 |
| `swir2` | SR_B7 | SR_B7 |

### 10.3 实现顺序
先验证目录与 MTL，再修复和重投影边界，生成唯一 grid.json 与 aoi。每期在源网格读取 QA 和六波段，计算无效掩膜并转换物理量，再重投影到公共网格。最终 valid_sr 需同时满足 AOI、重投影掩膜与六波段有限性。写入 SR、valid、来源及检查报告后才标记阶段成功。
对 2021 年同一 L1 场景的 RGB 与 B8，按 MTL 增益、偏移和太阳高度角转换 TOA，再全色锐化。输出必须带 `radiometry=TOA`、`purpose=visualization`，禁止进入 features 输入选择器。展示缺失不会阻断 30 m 主分析，但交付清单须说明该项状态。

### 特征和样本提取开发细则
$$NDVI = \frac{nir - red}{nir + red}$$
$$NDBI = \frac{swir1 - nir}{swir1 + nir}$$
$$MNDWI = \frac{green - swir1}{green + swir1}$$
$$BSI = \frac{(swir1 + red) - (nir + blue)}{(swir1 + red) + (nir + blue)}$$

### 10.4 数值处理
十维顺序为 blue、green、red、nir、swir1、swir2、NDVI、NDBI、MNDWI、BSI。总体方案用指数大写书写；既有配置字段为 ndvi、ndbi、mndwi、bsi 小写。实施以现有配置字符串为准并做显示别名映射，不在模型中混用大小写；P0 冻结机器字段。任一输入为 NoData、NaN、Inf、掩膜不等于 1，或任一指数分母为 0，则整条向量无效。不得以 0 填补缺失指数；0 是可能合法的物理特征值。对接近零分母是否设置 epsilon 属新增科学选择，首版按原方案“等于零”实现；任何阈值化须评审并留痕。
窗口读取 SR，利用显式有效布尔数组计算指数，在输出初始化为 -9999 的数组中仅填合法位置。写完每块检查十维共同有效性；不能让部分波段有值、部分缺值的像元进入推理。每个输出 band 写入精确名称，读取时核对 metadata 与配置。

### 10.5 像元提取
先冻结按组划分，再按像元中心落面规则提取。边界中心恰在多面公共边界时采用明确、确定性的归属策略，若导致跨类别归属冲突则报错人工处理。每年单独输出训练表和留出表，额外生成按类组数、像元数、置信度、空间范围的统计摘要。
较大数据可内部使用列式或二进制缓存提升性能，但正式 CSV 字段与顺序必须稳定；缓存不能绕过 split。抽样限制若用于控制训练规模，应只作用于训练集并按固定种子与类别规则执行，记录选中像元索引；不能改变留出集来提升指标。

### 10.6 阶段验收
检查原始输入 hash 未变化，组与像元交集为空，四类均有可用训练和验证像元，特征范围有限且顺序一致，输出行数与摘要一致。发现无有效像元的地块组须作为数据质量错误记录；不能名义满足 8 组、实际只有少数组参与训练。

## 11 分类模型和整景推理

### 11.1 随机森林主线
每年单独训练 RandomForestClassifier：`n_estimators=300`、`min_samples_leaf=2`、`max_features="sqrt"`、`class_weight="balanced_subsample"`、`random_state=42`。记录训练样本数、类分布、特征重要性、耗时、软件版本和资源参数。n_jobs 属运行资源参数，应与两期并发预算协调；不能每个进程都自动占满全部核。
训练仅访问 train.csv。训练结束后保存模型和元数据，在固定夹具和固定真实窗口上比较保存前后预测，应逐像元一致；hash、加载兼容和预测一致证据齐全才登记 model_id。Joblib/Pickle 可执行反序列化代码，只加载项目可信渠道产生且校验通过的模型。

### 11.2 最大似然基线新增任务
最大似然比较是最新总体方案要求，但固定提交尚无该实现；W13 必须列为新增算法和测试预算，不能标成既有能力。
基线使用相同四类、特征和训练/验证划分，按类估计均值与协方差，以多元高斯判别函数分类。协方差奇异、样本不足和特征共线时必须显式处理。若需正则项、先验分布或特征标准化，预先登记规则，仅在训练数据拟合；不能在看到 holdout 后替换基线设置。保存基线参数与失败原因，不以“算法传统”省略可复现证据。

### 11.3 窗口推理
按 512×512 读取十维特征，边缘窗口使用实际尺寸。输出数组先置 0，仅对十维全部有效且在 AOI 内的像元预测；检查预测只含 1 至 5，再还原窗口。每块结束可记录已完成窗口数；实时事件和协作取消属于附录 C 的新增扩展，不是现有 CLI 承诺。不得整景一次 reshape 后常驻内存，也不得遗漏最后一行或一列窗口。
按真实 dtype 估算峰值内存：十维 Float32 的单个 512×512 特征块约 10 MiB，但有效索引、副本、模型和库缓存还会占额外内存。它不是整进程内存上限。16 GB 机器先以单 worker 基准测量，再决定能否并发两年；GDAL 缓存建议 512 MB，并记录实际单位及设置方式。

### 11.4 完成条件
文件可重新打开、公共网格完全一致、NoData 正确、像元数守恒、类别合法、模型引用完整。颜色表与名称从配置派生；训练精度不能填到独立评价栏。运行性能以实测机器、数据规模和时间记录，不承诺未经测量的分钟数。

### 后处理与独立精度评价
### 11.5 Sieve 与分类矢量化
对 raw 使用 GDAL Sieve，阈值 4 像元、8 邻域，显式传入 raw!=0 掩膜。语义是处理小于阈值的连通斑块，不能误写为小于等于 4。保留 raw 与 final；比较二者 NoData 布局完全一致，并报告修改像元数量。Sieve 的邻接和替换由 GDAL 实现决定，用合成夹具核验而非凭视觉猜测。
final 矢量化跳过 0，裁剪到真实 AOI，修复几何后复核面积与类别。最新总体方案偏好 GPKG 内部标准，但固定核心现交付 SHP；首版必须保留 SHP 路径和验收，GPKG 可作经评审的新增副本，不无声替换。SHP 输出 .shp/.shx/.dbf/.prj/.cpg，UTF-8、字段名不超过 10 字符，并提供长短字段映射。SHP 的精度、字段和空值限制不能影响主统计表。

### 11.6 指标定义
混淆矩阵固定“行是真实、列是预测”，类别顺序 1 至 5，缺失类别仍保留行列。每类给出 support、Precision、Recall、F1 与 undefined 标记；分母为零不得静默写成完美分数。OA 为对角线和除以总验证数；无验证数据时评价失败，不返回 0 或 1。
$$OA = \frac{\text{正确预测的验证像元数}}{\text{全部有效验证像元数}}$$
$$F1 = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$
在冻结 holdout 的行列位置分别读取 raw、final 并与标签比较；有效性异常应报告被排除样本及原因，不能自行缩小验证集。最终门禁读取 final OA 的未舍入值，两年分别判断；建设用地 F1 单列。报告同时展示组数与像元数，避免大地块像元数多而被误解为大量独立证据。

### 11.7 评价授权
在最终评价前形成协议签认单，列明模型、split、后处理参数及不可继续调参的规则，由验收角色确认；CLI 运行前核验该记录，另存 evaluation_protocol.json。报告包含主要误分对、季节差异、样本来源和空间覆盖局限。分类精度不是变化精度；如无独立变化验证样本，必须在变化报告中明确该限制。

## 12 变化检测与面积统计

### 12.1 变化真值表
| 1992 建设状态 | 2021 建设状态 | 变化编码 | 统计归属 |
| :--- | :--- | :--- | :--- |
| 是 | 是 | 1 持续建设 | persistent |
| 否且有效 | 是 | 2 新增建设 | added |
| 是 | 否且有效 | 3 减少建设 | lost |
| 否且有效 | 否且有效 | 4 持续非建设 | nonbuilt_persistent |
| 任一期无效 | 任意 | 0 NoData | 不参与建设及变化面积 |

先核验两期 final 网格、类别与来源；在 AOI 内且两期类别均合法时 valid_common=1，区内任一期无效为 0，区外为 255。仅 mask==1 才写变化类。分类中 0 不是“非建设”，不能参与真值表。

### 12.2 几何相交统计
将变化栅格矢量化，与修复并去重后的 2021 街镇边界求交，面积在 EPSG:32648 中计算。使用空间索引加速但不得改变结果。边缘像元按相交面积分摊，不以像元中心分配整块 900 m²。街镇重叠会导致重复计量，必须在统计前门禁阻断或记录经批准的修复方案。
对每个单元输出 total_area、comparable_area、valid_ratio、built_1992、built_2021、persistent、added、lost、net、annual_net、annual_intensity。上述为概念名称。内部几何面积按 m² 计算；既有正式 CSV 使用带 _km2 后缀的 km² 字段，必须保留，不能无声改单位。完整表头见下段。
既有 15 列为 `unit_id`, `name`, `unit_type`, `boundary_year`, `total_area_km2`, `comparable_area_km2`, `valid_ratio`, `built_1992_km2`, `built_2021_km2`, `persistent_km2`, `added_km2`, `lost_km2`, `net_km2`, `annual_net_km2`, `annual_intensity_pct`。QGIS 只关联该表，不另算一套面积。
$$\text{net} = \text{built}_{2021} - \text{built}_{1992} = \text{added} - \text{lost}$$
$$\text{annual\_net} = \frac{\text{net}}{29}$$
$$\text{annual\_intensity} = \frac{\text{net}}{29 \times \text{total\_area}} \times 100\%$$

### 12.3 缺测与分母
上述 built_1992 和 built_2021 都限定共同有效区，使净增量可比。annual_intensity 的分母按原方案使用 29×total_area，不能偷偷改为 comparable_area。valid_ratio=comparable_area/total_area；total_area 非正是边界错误。comparable_area 为 0 时，建设及变化指标留空，状态为“无共同有效观测”；这不等于零扩张。

### 统计验证与制图产品
### 12.4 面积平衡与待修复差距
固定源码目前先将 CSV 指标 round(...,6) 再合计，全区无共同观测时仍有填 0 的分支；它们与最新总体方案不完全一致。W18 必须补测试并修复为未舍入内部运算、最后显示舍入，以及无观测指标留空；在修复验收前不得声称现有核心已满足。
逐街镇及全区检查：built_1992=persistent+lost，built_2021=persistent+added，net=added-lost=built_2021-built_1992，comparable_area=四类变化面积之和。未舍入值用于计算和检查，报告最后一步才舍入。保留既有平衡容差 max(1e-6 km², 区级面积×1e-6)，用夹具核验实现；不得随结果扩大容差来消除错误。
全区汇总与街镇之和相等的前提是街镇恰好无重叠覆盖 AOI。若存在合法边界缺口，单列未分配面积和原因，不能直接宣布平衡通过。boundary_version、run_id、网格 hash 和有效面积解释放 statistics.meta.json 或 manifest，并用统计 CSV hash 绑定；不增改既有 15 列。

### 12.5 样式与布局
土地覆被配色读取 configs/project.toml，QML、图层图例和布局图例同源。既有四类颜色依次为 `#D95F02`、`#E6C84F`、`#2E8B57`、`#377EB8`；变化颜色当前定义在 analyze.py，不在 QGIS 中再手写另一份，P0 冻结受控映射并测试一致性。NoData 透明；持续建设、新增、减少与持续非建设使用可区分颜色及文字，不让仅靠红绿颜色区分的读者无法辨认。展示融合图置于“展示”组并在图层名和布局说明标注“15 m TOA 仅辅助判读”。
专题图至少包含两期土地覆被、建设变化、街镇扩张强度。布局固定研究区范围与比例，统一坐标系、图例顺序、指北针、比例尺、来源、影像日期、边界年份和制作版本；比较图不得各自自动拉伸到不同范围。地图标题不使用没有证据的结论性词语。

### 12.6 工程可移植性
工程路径为 `qgis/xindu_1992_2021.qgz`。设置相对路径后保存，并生成 `project_manifest.json`，列明项目根、图层相对路径、artifact_id、hash、样式、布局模板和 CRS。迁移验收把交付目录复制到不同根目录、包含空格和中文路径的位置，断开原位置后打开工程，确认无坏图层、统计连接完整、地图可导出。仅保存 .qgz 不是可移植交付。

### 12.9 人工地图复核
逐图查看分类图例、边界、有效覆盖、中文字体、比例尺、指北针、数据来源与图面裁切。双期图并排比较范围/色表/图例一致；变化图核对一个新增、减少、持续建设和缺测位置；街镇图抽查表格值与分级颜色。视图美观不能掩盖错误统计，发现不一致先回溯源表和逻辑，不手工改颜色使结果看起来合理。

### 14.2 分支与合并
建议 feat/Wxx-short-name 分支，每个 PR 对应一个可验收工作包。主分支保护要求至少一名非作者复核、契约与单元测试通过。每天或完成一个接口切片后合并小批量变更；不要等全部 GUI 和算法分别做完才第一次联调。优先合并 schema 与 mock，再合并生产实现，最后删除临时适配。
共享接口变更先发 RFC，包含原因、受影响字段、迁移方案、测试、文档与批准人；L 更新 schema_version 和兼容表后，下游按新版本同步。禁止两个分支分别定义同一 logical_id 或统计字段含义。冲突由文件所有者解决，复核人与其核对语义；不接受简单“全部取我的版本”。

### 14.3 合并失败与回退
发现主分支回归，先冻结新合并并定位最小引入提交；可逆且独立的变更用 revert，不重写共享分支历史。保留失败日志与夹具，修复后补回归测试再合并。算法产物依赖 hash 变化时创建新 run；代码回退不等于可以继续使用与新配置混合的旧结果。里程碑标签与 manifest 提交号必须对应。

### 14.4 资源并发
同盘大栅格重投影和两份全核训练可能互相拖慢。运行负责人统一安排进程数、内存预算与同时写入数。首版默认一个重计算阶段运行，双期并发作为实测后启用的配置；文档“并发开发”不意味着无限并发计算。

## 15 合成夹具与单元测试

### 15.1 夹具原则
夹具必须小、确定、合法、无需网络，附生成脚本和手算期望值；不得包含真实敏感标签。建议以 8×8 或 16×16 公共网格测试 QA、掩膜与变化，以较大的非整窗口尺寸测试 512 窗口边界。地理坐标可选合法 UTM 米制原点，但在夹具说明中明确为人工构造。

| 测试 ID | 输入或反例 | 明确期望 |
| :--- | :--- | :--- |
| **UT01 比例因子** | DN=10000 与 NoData | 有效 SR=0.075；无效保持 -9999 |
| **UT02 QA** | 逐位设置 Fill/Cloud/Water 等 | 剔除指定无效位；单独 Water 保留 |
| **UT03 网格** | 同 CRS 但平移 15 m | 报 E_GRID，不能凭 CRS 相同通过 |
| **UT04 指数** | red=.2、nir=.6 | NDVI=.5；任一分母零整向量无效 |
| **UT05 掩膜** | 0、1、255 三个值 | 只有 1 参与；255 不被 bool 误收 |
| **UT06 分组** | 同组多个面、跨类组、重复像元 | 同组只在一侧；冲突阻断 |
| **UT07 推理** | 513×517 特征与边缘 NoData | 所有边缘窗口覆盖，NoData 为 0 |
| **UT08 持久化** | 同模型保存与重载 | 固定输入预测完全相同 |
| **UT09 Sieve** | 3 像元斑块、4 像元斑块、对角邻接 | 核验 <4 与 8 连通；0 边界不变 |
| **UT10 变化** | 四种有效组合加任一期 0 | 分别输出 1/2/3/4/0 |
| **UT11 相交面积** | 900 m² 像元被边界均分 | 两侧各 450 m²，不整像元归属 |
| **UT12 缺测** | 共同有效面积为 0 | 指标空值，状态无共同有效观测 |

### 15.2 手算统计夹具
构造单元总面积 3600 m²，共同有效区 2700 m²：持续建设、新增、减少各 900 m²，持续非建设 0。则 valid_ratio=0.75，built_1992=built_2021=1800，net=0，annual_net=0，annual_intensity=0。这些是测试期望值，不是研究区统计结果。另加含半像元边界与非零净增长的夹具，避免仅用净零样例漏测符号错误。

### 集成和界面测试
### 15.3 科学有效性专项
检查训练入口不使用 holdout；新增校验器应使 split hash 改变的模型失效（现有自动失效机制须补实现）；特征列交换和两期模型互换必须报错；OA=0.75 失败、略大于 0.75 才通过。F1 目标未达可产生报告，但须显示警示。用非对称混淆矩阵检查 Precision/Recall 方向，不只测试对角矩阵。

### 15.4 故障注入
| 场景 | 操作 | 期望行为 |
| :--- | :--- | :--- |
| **磁盘不足** | 候选工程/地图写入失败 | 失败报告，旧工程不覆盖 |
| **中文及空格路径** | 输入输出迁移 | 可解析，不拼 shell 命令 |
| **缺失数据源** | 移走一个必需文件 | release 阻断并列完整缺口 |
| **重复构建** | 对同一夹具连续构建两次 | 图层、布局、join 不重复 |
| **统计键冲突** | 重复或缺失 unit_id | 阻断正式关联，不多对多 |
| **无观测单元** | 统计指标为空 | NULL 保留，不渲染成真实零 |
| **GPKG 并发写** | 同一文件开启第二写者 | 交接规则阻止，不关闭锁机制 |
| **数据变化** | 构建后替换输入内容 | hash 校验不符，标记工程过期 |
| **旧工程格式** | 只提供 qgs 而合同要求 qgz | 转换并真加载验证，不改名冒充 |
| **布局导出失败** | 非法路径或缺失字体/图层 | 返回码与目视检查均不能通过 |

### 15.5 QGIS 行为验收
用干净用户配置启动 QGIS，执行探针与构建，打开图层、表单、统计 join 和布局，导出四图，保存后重开，再迁移根目录复核。检查 isValid、图层组、离散渲染、NoData、中文字段、前导零和地图范围。关闭工程时保留 QGIS 未保存编辑提示；脚本不得擅自保存或删除用户内容。
性能记录机器、数据规模、版本、缓存和线程；观察窗口内存、加载时间及导出耗时。不设未经测量的秒级承诺。核心合成测试、PyQGIS 集成、真实数据验收三层分开，缺环境/数据分别写 NOT RUN 或 BLOCKED。

## 18 安全与故障恢复手册

### 18.1 安全底线
项目默认本地处理，不需要上传遥感影像、样本或个人目录到外部服务。工程脚本不保存账户密码；若来源下载需要凭据，使用系统安全机制或由用户在受信工具中完成。日志脱敏用户名路径、令牌与签名 URL；报告只保留必要来源信息。样本解释者标识限项目内部用途。
执行外部进程只用已验证可执行文件和参数数组，拒绝 shell=True 及拼接输入。文件名、配置和模型元数据均按不可信输入校验；禁止任意 eval、执行来自项目文件的脚本和自动加载未知 joblib。路径规范化后确认在授权根目录内，不允许输出覆盖 raw。

### 18.2 常见故障
| 现象 | 优先检查 | 安全处理 |
| :--- | :--- | :--- |
| **QGIS 能开但离线计算失败** | 可执行路径、环境探针、依赖 | 修复独立环境，不向 QGIS Python 混装包 |
| **数据看似重叠但变化异常** | transform、grid_id、像元原点 | 退回公共网格重建，禁用自动对齐掩盖 |
| **分类边缘出现假新增** | 0/255 处理、共同有效掩膜 | 修正掩膜逻辑并重跑受影响下游 |
| **精度异常高** | 组与像元泄漏、同地块改名 | 冻结发布，复核 split 与独立证据 |
| **街镇面积总和超全区** | 边界重叠、重复 ID、单位 | 修复来源或明确合法差异后重统计 |
| **取消后 CPU 仍繁忙** | 所属派生进程与句柄 | 按所属进程树清理，禁止全局杀 Python |
| **工程在他机缺图层** | 相对路径、清单、交付遗漏 | 补完整产物并重新迁移验收 |

### 18.3 备份与保留
原始数据按来源 hash 保留只读副本；标签与 split 每个冻结版本保留；正式模型、配置、manifest 和指标长期随课程成果归档。大型中间文件可按批准策略清理，但须保留重建所需输入与参数。清理前列出将删除的 run 和依赖，禁止自动删除仍被 QGIS 工程引用的产物。
恢复演练在复制的夹具目录执行，模拟中断、残留锁、.partial、输出损坏和配置变化。演练通过后，才将阶段重跑步骤纳入操作手册。恢复不会替用户批准科学口径变更。

## 附录 C 可选交互扩展边界
本附录不属于本期必需工作包。仅在用户明确需要按钮或 Processing 入口并批准范围变更后实施；不得把这些能力描述为当前已有。

### C.1 薄适配而非重写
自定义插件只负责参数、环境选择、进程启动、日志和结果加载，仍调用既有 CLI/核心。initGui 与 unload 对称处理菜单、信号和 provider。QGIS 内部轻量任务可用 QgsTask；后台不得访问主线程 QgsProject、QgsVectorLayer 或 QWidget，context/feedback 必须存活到任务结束。processing.run 本身不自动异步。

### C.2 可选进程协议
新增 worker 才能承诺 JSONL 进度、结构化错误或协作取消。请求含 job_id、schema_version、阶段、年份、输入/配置 hash、输出目录；事件含 seq、job_id、stage、completed、total、message；stderr 存诊断并持续排空。GUI 拒绝旧 job_id 回调，终态只能提交一次。退出码 0、成功事件和产物校验三者都满足才成功，不解析日志自然语言判断。

### C.3 取消与事务
先发取消标记，在块/阶段边界检查并关闭数据集；超过经测试的宽限期后，终止该作业专属进程组或 Windows Job Object，等待整棵派生树退出。仅 QProcess.kill 或 Popen.terminate 不能证明子孙进程全部终止。不得按名称杀死其他 Python/QGIS。
输出写专用 staging，关闭句柄、校验后同盘原子提交；多文件产物采用目录或提交清单，不能跨盘假称原子。取消和失败产物不得缓存命中。每作业限制外层并发、n_jobs、BLAS/OMP、GDAL 线程，避免嵌套过载。该扩展需新增完整事件、取消、卸载和竞态测试，不占用本期关键路径。
