### 2.2 预处理与质量控制规范
1. **地表反射率（SR）定量转换：**
   $$\rho_{\lambda} = \text{DN} \times 0.0000275 - 0.2$$
   - 原始 Fill 像元（DN=0）与饱和像元排除；
   - QA_PIXEL 掩膜：排除云（Bit 3）、云阴影（Bit 4）、卷云（Bit 2 OLI）；严格保留水体像元（Bit 7），严禁仅依据 Clear 位掩膜。
2. **统一空间网格：**
   - 统一对齐到 `data/processed/grids/grid_30m.json`（外包框按 30m 整数网格向外扩整）；
   - 反射率采用双线性内插重采样，有效掩膜与类别采用最近邻重采样。
3. **15 米全色融合影像：**
   - 采用同景 Landsat 8 L1 RGB 与 B8 全色波段，统一转换至 TOA 反射率后进行 Gram-Schmidt / Brovey 锐化融合；
   - 标注 `radiometry=TOA`、`purpose=visualization`，不作为 30 米定量分类的特征。

## 3. 分类体系、特征工程与空间独立样本

### 3.1 五类土地覆被分类标准
依《公共契约 v1》及《遥感解译手册》，严格划分为 5 类，0 为 NoData：
1. **建设用地（代码 1，配色 `#D95F02`）：** 城乡居住建筑群、工厂园区、仓储物流、交通硬化地表、农村硬化院落（不含未铺装裸土地基）。
2. **耕地（代码 2，配色 `#E6C84F`）：** 水田、旱地、蔬菜大棚、休耕田块。
3. **其他植被（代码 3，配色 `#2E8B57`）：** 乔木林、灌木林、果园、苗圃、绿化公园、荒草地。
4. **水域（代码 4，配色 `#377EB8`）：** 天然河流、水渠、水库、坑塘水面。
5. **裸地（代码 5，配色 `#B69C7D`）：** 沙石河滩、平整待建工农业推土裸地。

### 3.2 10 维特征工程与公式
特征图固定为 10 维 Float32，顺序如下：
$$\text{Features} = [\text{blue}, \text{green}, \text{red}, \text{nir}, \text{swir1}, \text{swir2}, \text{NDVI}, \text{NDBI}, \text{MNDWI}, \text{BSI}]$$
- $\text{NDVI} = (\text{nir} - \text{red}) / (\text{nir} + \text{red})$
- $\text{NDBI} = (\text{swir1} - \text{nir}) / (\text{swir1} + \text{nir})$
- $\text{MNDWI} = (\text{green} - \text{swir1}) / (\text{green} + \text{swir1})$
- $\text{BSI} = [(\text{swir1} + \text{red}) - (\text{nir} + \text{blue})] / [(\text{swir1} + \text{red}) + (\text{nir} + \text{blue})]$
- **无效性规则：** 若任一指数分母为 0 或输入波段无效，整景 10 维特征标为 NoData (`-9999.0`)。

### 3.3 空间地块组隔离与分层留出原则
- **地块组原则（Spatial Grouping）：** 标注以物理地块为单元，赋予唯一 `group_id`。同一地块不拆组，严禁像元尺度随机抽样。
- **留出划分：** 固定随机种子 42，按类别分层执行 `GroupShuffleSplit`，留出 25% 的地块组（每类 $\ge 2$ 组）作为冻结验证集（Holdout），划分元数据固化于 `split.json`。

## 4. 模型分类、后处理与独立精度评价

### 4.1 随机森林参数与去噪后处理
- **随机森林配置：** `n_estimators=300`，`min_samples_leaf=2`，`max_features='sqrt'`，`class_weight='balanced_subsample'`，`random_state=42`。仅使用 `train.csv` 拟合，模型特征顺序严格绑定。
- **后处理（Sieve 去噪）：** 采用 GDAL Sieve 算法，连通性 8 邻接，面积阈值 4 像元，消除孤立噪声并保护真实边界；有效掩膜采用 `raw != 0` 显式布尔逻辑，不填补外部 NoData。

## 5. 1992—2021 年新都区建设用地时空扩张分析

### 5.1 变化检测科学口径与掩膜
- **共同有效掩膜（Common Valid Mask）：** 仅在两期 Landsat 最终分类均具有效非零值、且均落在新都区边界内的区域计算变化；排除任一时相受云遮挡、阴影或传感器边界缺失像元，避免将单期观测缺失误判为真实地类变化。
- **四类变化状态编码：**
  - **1 = 持续建设（Persistent）：** 1992 年建设用地 $\rightarrow$ 2021 年建设用地
  - **2 = 新增建设（Added）：** 1992 年非建设用地 $\rightarrow$ 2021 年建设用地
  - **3 = 减少建设（Lost）：** 1992 年建设用地 $\rightarrow$ 2021 年非建设用地（生态退耕、复绿、复垦拆迁）
  - **4 = 持续非建设（Persistent Non-built）：** 1992 年非建设用地 $\rightarrow$ 2021 年非建设用地
- **数学平衡方程：**
  $$\text{net\_km2} = \text{added\_km2} - \text{lost\_km2} = \text{built\_2021\_km2} - \text{built\_1992\_km2}$$
  $$\text{annual\_net\_km2} = \frac{\text{net\_km2}}{29}$$
  $$\text{annual\_intensity\_pct} = \frac{\text{net\_km2}}{29 \times \text{total\_area\_km2}} \times 100\%$$

## 6. 科学局限性与严谨性说明

1. **时相跨季节差异（Seasonality Limitation）：**
   - 1992 年影像为 8 月（盛夏，作物繁茂水热同季）；2021 年影像为 2 月（初春/越冬，部分耕地休耕或裸露）。
   - 该季节差异对耕地、其他植被及裸地的区分可能带来光谱类内变化；通过结合多时相历史资料与 BSI/MNDWI 联合辅助判读予以消解。
2. **建设用地定义与地表硬化边界：**
   - 遥感建设用地定义涵盖城乡实体硬化地表、工业园区与农村集中硬化居民点；
   - 本项目统计口径为“地表物理建设用地扩张”，不直接等同于国土空间法定规划编制的“城市建成区（Built-up Area）”。
3. **可比范围与数据缺失说明：**
   - 变化统计严格建立在“共同有效观测面（Intersection of Valid Pixels）”之上；
   - 若个别像元因云覆盖或传感器边缘未测，该区域在统计中如实列为未观测，不推测或插值为零扩张。
4. **29 年区间平均口径局限：**
   - 本研究为两期静态对比，年均净增与年均扩张强度为 29 年区间平均指标，不能推断新都区各具体年份（如 2000 年撤县设区、2008 年震后重建）的突变峰值。
