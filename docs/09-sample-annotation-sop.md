## 2. 建标注工程

### 2.1 加载底图（栅格）

`图层 → 添加图层 → **添加栅格图层**`（Add Raster Layer），依次加载这三张 **TIF**：

| 用途 | 文件 | 显示设置 |
| --- | --- | --- |
| **2021 主判读底图（15 m 真彩色）** | `outputs/rasters/xindu_2021_pan_rgb_15m.tif` |  symbology：波段 1-2-3 → R-G-B；最小值/最大值选「累计计数裁剪 2%–98%」 |
| **2021 假彩色（30 m，看植被/水体更准）** | `outputs/rasters/xindu_2021_sr_30m.tif` | 波段 **4-3-2** → R-G-B（4=NIR，3=红，2=绿）；拉伸 2%–98% |
| **1992 判读底图（30 m 假彩色）** | `outputs/rasters/xindu_1992_sr_30m.tif` | 同上，波段 **4-3-2**，拉伸 2%–98% |

> 反射率是 0—1 的小数，直接加载会显示成全黑或全白，**必须做 2%–98% 拉伸**，否则看不出地物。
> 需要「打开就清楚」的成品假彩色图，跟我说一声，我可以直接生成拉伸好的 GeoTIFF/PNG，省掉手动调参。

### 2.1b 加载边界（矢量，别用栅格图层按钮）

边界是 **GeoPackage 矢量**，**必须**用 `图层 → 添加图层 → **添加矢量图层**`（Add Vector Layer）：

1. 源类型（Source type）选「**文件（File）**」；
2. 数据集（Dataset）填 `E:\工程实践3\GCSJ3\data\processed\boundaries\xindu_2021.gpkg`，点「添加」；
3. 弹出子图层列表后，**勾选 `townships`（9 个镇街）和 `study_area`（研究区）**，确定；
4. 两者都设成「仅描边、不填充」，`townships` 线宽 1.5，`study_area` 用虚线。

更快的办法：直接用 **浏览器（Browser）** 面板 → 展开到那个 `.gpkg` → 双击 `townships` 图层即可。

> ⚠️ 如果看到报错 `不支持的数据源 ... 不是一个受支持的栅格数据源 ... 该栅格文件不包含任何波段`，说明点成了「添加**栅格**图层」。这个 gpkg 里只有两个矢量面图层（`townships`、`study_area`），没有波段，栅格方式当然打不开——换「添加矢量图层」就好，文件本身没问题。

## 3. 标注规则

### 3.0 画什么（新手先看这节）

**不是随便画。** 你画的每一个面都会变成模型的训练样本和评分依据，画的必须是「**一整块、内部同类、够大**」的地物，不是地图上所有东西。

| 类 | 优先画这些（新都区里好找的） | 面的大小 | 别画 |
| --- | --- | --- | --- |
| **1 城镇及建设用地** | 新都城区成片街区、大丰/斑竹园的连片厂房与仓储、镇区密集居民点、成片硬化物流园 | ≥5×5 像元（150 m 见方） | 单栋农房、窄村道、田边小院（太小，全是混合像元） |
| **2 耕地** | 平坝区大片规则田块（水稻田、菜地、大棚区）、成片冬闲田 | ≥5×5 像元，大田块可整块画 | 田埂、机耕道、零星菜园 |
| **3 林草植被** | 毗河/锦江沿岸林带、成片苗圃、桂湖公园等成片绿地、川西林盘竹冠 | ≥5×5 像元 | 行道树、房前屋后零星几棵、半树半房的林盘边角 |
| **4 水体** | 毗河等干流宽水面、干渠、水库、成片鱼塘/坑塘群 | ≥5×5 像元（河面窄处顺着河道画长条） | 田沟、小水渠、有大量水草的浅塘 |

三条硬要求：

1. **一个面内只能有一种地类**。跨了地类边界就拆成两个面，或缩到边界内。
2. **面不要贴边、不要压云**。压到云、云影、影像边缘（研究区外的黑边）的面，提不出有效像元，白画。
3. **同一块地不要画两遍**。面互相重叠会让同一像元被算进两个组，代码会报错。

数量分配（2021 与 1992 各一套）：

| 类 | 组的数量 | 面的大致个数 |
| --- | --- | --- |
| 1 城镇及建设用地 | 8—10 组 | 10—15 个面 |
| 2 耕地 | 8—10 组 | 10—15 个面 |
| 3 林草植被 | 8—10 组 | 10—15 个面 |
| 4 水体 | 8—10 组 | 8—12 个面 |
| **合计** | **32—40 组** | **约 40—60 个面** |

**一家组 = 一处地方**：同一个 group 内可以画 2—3 个相邻面（比如同一片厂房被路切成几块），它们的 `group_id` 相同；不同 group 之间要**隔开至少几百米**，最好落在不同镇街。

顺序建议：**先把 1 类标够 8 组 → 再 2 类 → 3 类 → 4 类**。按类聚着标，判读标准不会漂。

### 3.1 四类判读要点

| 类 | 判读 | 易错 |
| --- | --- | --- |
| **1 城镇及建设用地** | 成片房屋、厂房、仓储、硬化道路广场、农村硬化院落、**在建工地与推平待建地** | 别把田埂、机耕道画进来；别把大棚当建筑 |
| **2 耕地** | 规则田块、水田旱地菜地大棚、休耕田、**翻耕后暂时裸露的田** | 1992-08 是生长期，红得发亮；2021-02 冬闲田偏灰，按田块轮廓判 |
| **3 林草植被** | 成片林、苗圃、公园绿地、荒草地、**川西林盘竹冠** | 林盘常与房屋混杂，选**竹冠所占比例高**的整块，避开半树半房 |
| **4 水体** | 河流、渠、水库、坑塘、养殖水面 | 枯水期河床砂石滩不算水体（见 §3.2） |

### 3.2 原「裸地」怎么归

| 情形 | 归入 |
| --- | --- |
| 在建工地、推平待建地、开挖未铺装 | **1** |
| 翻耕裸田、冬水田干涸田面 | **2** |
| 河床砂石滩 | 常水位岸线以内 → **4**；岸线以外滩涂 → **2** |
| 浅丘裸露土坡、坡耕地土坎 | **2** |

不得新造第 5 类。

### 3.3 `group_id` 怎么编

- 格式：`c{类号}_g{序号:02d}`，如 `c1_g01`、`c4_g12`。
- **一个物理地块 = 一个组**；同一地块被道路切开或中间夹杂小地物，仍算同一组，多个面共用一个 `group_id`。
- 空间上不相邻、相隔较远的才算不同组。
- 一个 `group_id` 只能对应一个 `class_id`（代码会强制检查，违反直接报错）。

### 3.4 数量与分布

- 每类 ≥8 组，**分散在不同镇街**（9 个镇街尽量都覆盖），避免同类样本全挤在一个片区——否则留出验证会虚高。
- 组数够之后再多标 2—4 组做容错。

## 4. 操作步骤（QGIS 里一步步）

1. 选中 `labels` 图层 → 点工具栏 **铅笔（切换编辑模式）**；
2. 点 **添加多边形要素**，沿地物边界点击顶点，右键结束；
3. 弹出属性框，填 `sample_id`、`group_id`、`year`、`class_id`、`label_source`、`source_date`、`annotator`；
4. 每标完一批点数字化工具栏的「**保存图层编辑**」软盘（Ctrl+S 只存工程，不存图层编辑）；
5. 标完点铅笔退出编辑模式。

小技巧：

- 按住 `Shift` 点顶点可画直角边；
- 先按类别集中标（先把 1 类标够 8 组，再标 2 类），比来回切换判读标准更稳；
- 不确定的地物**不要标**，宁可少标也不要标错——错标比缺标危害大得多。

## 7. 1992 年的特别说明

- 1992 只有 30 m 假彩色，**没有 15 m**，边界不如 2021 清楚，判读时优先看田块轮廓和河网走向；

## 8. 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Required input labels vector not found` | 文件没放到 `data/samples/{year}/labels.gpkg` | 检查路径与文件名 |
| 图层名不是 `labels` | 建成了别的名字 | 重命名或重建 |
| `Class X has N groups, which is less than 8` | 某类组数不够 | 补标该类 |
| 同一 group_id 对应多个类别 | 复制要素后忘改 group_id | 改 group_id |
| 提取到的像元数为 0 | 面太小或压在云/无效像元上 | 换位置、画大一点 |
| CRS 不是 32648 | 新建时选了别的坐标系 | 重新投影后再导出 |
| `不支持的数据源 ... 不是一个受支持的栅格数据源`、`该栅格文件不包含任何波段` | 用「添加**栅格**图层」打开了 `.gpkg` 矢量文件 | 改用「添加**矢量**图层」，或浏览器面板双击子图层（见 §2.1b） |
| 矢量图层打开后提示「选择要添加的子图层」 | gpkg 含多个图层（`townships`、`study_area`） | 勾选需要的子图层；全选也可以 |
| 底图是黑的、边界也看不见 | 栅格未拉伸 + 矢量样式默认实心填充盖住底图 | 栅格做 2%–98% 拉伸；矢量改「仅描边」 |
